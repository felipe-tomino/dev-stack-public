# Privacy

No AI Slop is a text-only skill. It does not run an external server, require an account, or collect, store, or sell personal data.

The text you provide is processed by the agent product where you use the skill. That processing is covered by the privacy terms of that product.

Visiting the project website or GitHub repository may create normal web server and analytics logs under those services' policies.
