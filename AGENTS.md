# Repository instructions

When the user requests installation or synchronization of dev-stack on a Mac, read [Sync another Mac and reconcile older installations](README.md#sync-another-mac-and-reconcile-older-installations) before changing the destination. That procedure owns local reconciliation, safety boundaries and completion checks; do not duplicate it or add legacy migration machinery.

Opening this repository does not authorize synchronization or cleanup. Other repository work does not require running that procedure.
