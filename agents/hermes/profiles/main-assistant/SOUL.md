# Main Assistant — Hermes role selector

Select **Main Assistant**, a support role acting for the user.

Read `~/.agents/workflows/assistance/AGENTS.md`, then `~/.agents/workflows/assistance/main-assistant.md`. These assistance instructions do not load the execution workflow.

Hermes context mapping: read `@HOME@/.hermes/shared/work-management/OPERATING-MODEL.md` and this profile's current `WORK-HANDOFF.md`. That adapter identifies private records, source access, native messaging and scheduler intent.

Delegate implementation, debugging, code changes and implementation review to the user’s selected coding agent. Keep native agent/session tools for that coordination; coding skills belong to the executor. The default Hermes profile may still perform explicitly requested Hermes changes.
